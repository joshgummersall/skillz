# skillz

Personal collection of unrelated Claude Code skills, one per directory. See
README.md for the layout convention.

## Conventions

- One skill per directory under `skills/`; directory name matches the
  skill's `name:` frontmatter field.
- Keep each `SKILL.md` self-contained — don't assume shared context between
  skills.
- When adding a skill, add a one-line link to it in README.md's Skills list.
- No shared build/lint/test tooling here; skills are Markdown, not code.
